# 课程定名：《日常摄影实践》

2026-10-24，旅行者问起「摄影这门课有没有参考书，能不能改成书名式」。

先查了底：课程其实**早就约定了参考书**——《美国纽约摄影学院摄影教材》（上下册，人民邮电出版社），写在 `NOTES.md` 的「已做的决定」里，也出现在 `RESOURCES.md` 的「主教材」条目和各讲页脚的「推荐一手资料」。问题只是**课程对外显示的名字是中性词「摄影」**，看起来不像其他几门那样体例统一。

## 决策

- 课程显示名改为 **《日常摄影实践》**（用户拍板，"取名类似"）。
- 这是一个**自创讲义名**，不是出版书名。因此在 `NOTES.md` 里明确记录两者关系：**自建课程 + 对照原书**，《美国纽约摄影学院摄影教材》继续担任**骨干教材/一手参考书**，地位不变、措辞微调。
- 目录 slug **保持 `photography` 不变**（用户选择）：纯 ASCII、URL 稳、不必 `git mv` 全部路径。显示名与 slug 解耦——前端标题取自 `MISSION.md` 的一级标题，与目录名无关。

## 具体改动

- `MISSION.md`：一级标题 `Mission: 摄影` → `Mission: 日常摄影实践`（**首页卡片名就来自这里**）
- `lessons/*.html`（12 讲）与 `reference/*.html`（3 份速查）：页首 kicker `摄影 · 第 N 讲` → `日常摄影实践 · 第 N 讲`
- `reference/*.html`：`<title>` 尾部 `· 摄影` → `· 日常摄影实践`
- `RESOURCES.md` 标题：`# 摄影 Resources` → `# 日常摄影实践 Resources`
- `NOTES.md`：新增一条「课程定名」决定，说明自创名与原书的关系
- 内容本身**未改动**（用户选择「只改命名」）

## Evidence

用户在被给出三个选项（沿用真实书名 / 自创书名 / 书名+副标题）时，回答「取名类似，日常摄影实践？」，并同时选定「只改命名」与「保留 photography slug」。

## Implications

- 首页「摄影与审美」分组里的卡片现在显示《日常摄影实践》，与其余课程一样是书名式。
- 讲义正文里「本课程的骨干教材」等表述仍然成立，不必改。
- 若日后要按原书深度重构内容（把 12 讲扩成整本书的体量），那是一轮独立的工作，命名已为它预留了空间。
