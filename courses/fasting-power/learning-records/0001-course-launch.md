# Learning Record 0001 · 课程启动

- 日期：2026-10-23
- 状态：八讲 + 两篇速查，已完成

## 学习者意图

用户原话是「我想深度读一下控糖革命和空腹力」。这两本书经常被放在同一类
「代谢健康」书单里，但主张并不相同：一本让你把曲线压平，一本让你把空腹拉长。
课程的目标是让读者能自己判断：哪些主张有证据，哪些只是叙事。

## 初始画像（假设）

- 手机阅读为主，单次 10–20 分钟。
- 想要「能执行」的结论，但不愿意被执行方案绑架。
- 没有提供年龄、体重、用药、作息；因此所有方案都从最低风险档开始，并给出停止条件。
- 对「日本畅销书」的写法可能有戒心，课程不回避这一点，第一讲就拆出版史。

## 结构决策

原书八章是一条闭合的宣传链：过食致病 → 血液不净 → 断食治病 → 半日断食 → 保暖 →
饮食法 → 改变人生 → 活到一百岁。逐章讲会被它带着走。改为：

1. 一本畅销书与它的时代（先把书放回语境）
2. 过食致病：哪一半是真的（保留硬机制）
3. 血液不净与体寒：隐喻的边界（拆掉伪机制）
4. 断食时身体在烧什么（真正的生理学）
5. 半日断食法逐条拆解（把方案放上解剖台）
6. 热量限制与长寿：证据到哪一步
7. 16:8、5:2、隔日断食：证据版图
8. 谁不能断，以及怎么温和开始（风险与四周方案）

## 写作取舍

- 风险章节放在方案之前，且给出绝对禁忌与停止信号。
- 不写超过 24 小时的断食操作。
- 「自噬」只讲到「诺奖机制在酵母、人体无法常规测量」，不编小时阈值。
- 所有研究标人群与对照：断食 vs 随意饮食，和断食 vs 等热量限制，结论完全不同。
