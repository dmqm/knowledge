建立你自己的投资清单

一句话目标：这一讲不给你新知识，只把前九讲压成一张纸——它不告诉你买什么，只在你准备犯错的那一刻拦住你。

引子：知道，和做到

读到这里，零件你已经拿全了：买股票就是买公司；不懂不做；毛估估；生意模式与企业文化；发现错了马上改；还有一张不为清单。每一讲单独看都成立，合起来却仍然只是知识。

知识不等于行为。你在第 3 讲点头认同「能力圈外最明显的标志是狂跌时不敢加仓」，然后在某个开盘跌 7% 的早上把仓位清掉。那一刻你不是忘了，是情绪先到，原则后到。人在紧张时能调用的，往往只有印在纸上的东西，不是记在脑子里的东西。

所以这一讲只做一件事：把这些话变成一张你会真的拿起来看的纸。

如果不懂，作业是抄不了的。如果懂了，不需要抄。雪球，2024-08-08

这句话同样适用于清单。你可以先照着参考页抄一版，但抄来的清单只是别人的肌肉记忆。真正拦得住你的，是你自己写下的那几条——因为只有你知道，你上一次亏钱，是在哪个环节松的手。

为什么必须写下来

脑子里的原则有三个毛病：会变形，会遗忘，会自我美化。

会变形。 一年前你想的是「价格明显低于价值才买」，一年后它在你自己嘴里变成了「差不多到底了」。词没换，标准换了。写在纸上的句子不会跟着行情一起改，你至少能看见自己改过。

会遗忘，尤其是在赚钱之后。 人倾向于记住判断正确的部分，自动删掉当时其实在猜的部分。一份写在买入当天的三句话，是唯一没有后来行情污染的证据。

会自我美化。 事后你总能给任何结果编一个解释。但如果你当时写下了「我买它，是因为它明年要开一百家店」，而事实是它关了三十家，你就没有解释空间了。

写下来还有一个更实际的作用：逼你把模糊的词换成可判断的标准。「好公司」不是标准；「客户换掉它，产线要重新认证三个月」是标准。「便宜」不是标准；「按最保守的现金流打六折，仍低于现价」是标准。一个词能不能被验证，取决于你敢不敢把它写成一句完整的话。

最后提醒一句：清单的价值在于让你不通过，不是让你通过。它一次次把「我再看一眼」变成「不满足，先放下」。如果一年下来它没拦过你几次，要么是清单写得太松，要么是你根本没在看它。

四张表，构成你的系统

一套能用的系统不需要复杂。四张表就够：一张写你懂什么，一张写你不做什么，一张写买之前必须回答什么，一张写什么情况下必须卖。

表一：能力圈表。 四列——公司或行业、能不能说清它怎么赚钱、跌 50% 敢不敢加仓、结论。四列都不许留空。

公司 / 行业说清怎么赚钱腰斩敢加仓吗结论
（你在里面工作过的）能 / 不能敢 / 不敢圈内 / 圈外 / 待验证
（你最近想买的）能 / 不能敢 / 不敢圈内 / 圈外 / 待验证
（你亏过钱的）能 / 不能敢 / 不敢圈内 / 圈外 / 待验证

第三列是照妖镜。跌一半不敢加仓的公司，无论你读过多少研报，它都在圈外；这一点段永平说得很直白：

能力圈以外的东西最明显的标志就是，狂跌的时候也不敢加仓，解套就卖了。当我跑到能力圈以外的时候，和散户并没有区别。雪球，2022-03-09

结论只允许三个：圈内、圈外、待验证。「待验证」是你接下来要花时间的地方，不是可以买的地方。表里至少写五行，其中必须有一个你亏过钱的公司——那一行通常最诚实。

表二：不为清单。 不超过十条。关于条数，段永平的态度是：

我没有真的统计过我们的stop doing list有多少条，但似乎不是几十条那么多……要列入这个清单的东西一定要尽量少，不然可能会束缚大家的手脚。雪球，2019-08-06

关键不在条数，而在于每条都要挂着一个具体的错误。「要谨慎」不是条目，它没法执行；「不在财报发布前一天加仓」是条目，因为你当场就能判断自己在不在做。「不加杠杆」是条目；「控制风险」是口号。

写法建议：左边写禁令，右边写它防住了什么。写不出右边那句的，说明这条是从别处抄来的，删掉，腾位置给你真正犯过的错。

表三：买入前十问。 题目在投资清单里，答案必须是你自己的。规则很硬：每题写一句话，写不出就是没过。不许用「大概」「应该」「长期看好」收尾。

判断标准是能不能被别人看懂。写「有护城河」是空话；写「它的客户换供应商要停线两周重新认证，所以不换」才是答案。十问最大的作用不是筛公司，是筛掉你以为自己懂的那些。

表四：卖出触发条件。 提前写，不要等跌了再想。合法理由只有三条：逻辑被证伪；出现明显更好的机会；价格远高于价值。成本价不进入判断。

无论什么时候卖都不要和买的成本联系起来。该卖的理由可能有很多，唯一不该用的理由就是'我已经赚钱了'。网易博客，2010-03-27

写法：给每个持仓填一句可验证的话。「如果毛利率连续两年下滑超过五个点，说明定价权没了，我卖。」数字准不准不重要，重要的是你在冷静的时候做过这个决定，而不是在跌停的晚上临时想。表格里干脆不要设「成本价」这一栏。

复盘模板：判断决策，不判断盈亏

四张表管「做之前」。还有一张管「做完之后」，它比前四张都重要，因为只有它会让你的判断力真的变强。

每笔投资记五件事，一页纸：

  1. 买入理由三句话。 生意怎么赚钱；为什么是现在；我最担心什么。
  2. 当时的价格与毛估估区间。 写区间，不写点。区间的宽窄，暴露了你当时把握的大小。
  3. 后来发生了什么事实。 收入、毛利、客户、管理层动作。不是股价。
  4. 逻辑有没有变。 三句话里哪一句被证伪了，还是仍然全部成立。
  5. 下次怎么改。 改流程，不改心情。写「以后先查应收账款」可以；写「以后要更果断」等于没写。

第三项最容易写歪。股价是结果，不是事实。一家公司跌了一半而生意更好，和跌了一半而生意变坏，在复盘里必须是两件完全不同的事。只写股价，你复盘的其实是市场，不是自己的判断。

最重要的纪律：复盘的对象是决策质量，不是盈亏结果。 赚钱的错误决策也要记下来。你追热点赚了 40%，如果只用盈亏打分，这次「成功」会强化一个坏习惯，而它下次会带着更大的仓位回来找你。反过来，一笔亏了钱但逻辑成立、流程正确的投资，应该被标成「做对了」，不是「失败了」。

具体做法：每条记录贴两个标签，一个是「对的决定 / 错的决定」，一个是「赚 / 亏」。四个格子都要有样本，你才会真的相信这套东西在起作用。

节奏：两年一家，不是一天三次

关于节奏，段永平给过一个很冷静的数字：

我开始投资以来，真正搞懂的企业不超过10家，下重手的不超过5家，平均大概两年一家。2012

两年一家。这不是谦虚，是算术：真正看懂一家公司，要读几年财报、跟几轮经营周期、亲历一次行业低谷。这个工作量决定了你的上限，任何技巧都绕不过去。

所以给自己定一个能持续十年的节奏：一年认真研究三到五家，而不是一年交易五十次。研究完可以一家都不买——「看懂了但太贵」是一个合格的结论，而且是好结论。

三到五家也意味着你必须主动放弃。市场上每年有几百个故事，你只能挑几个真的弄明白。放弃不产生成本；看不懂却下注，才产生成本。

简单，但不容易

投资实在是太简单了，说来说去就一句话：买股票就是买公司。但理解公司不是一本书可以写的，所以投资真的很难写书。雪球，2024-06-12

这句话把整门课的难点讲完了。简单的是那一句，难的是「理解公司」四个字：它没有公式，没有穷尽，只能一家一家地啃。所以会出现一种奇怪的景象——道理人人都懂，做对的人极少。差别不在智商，在于愿不愿意花两年弄懂一家公司。

普通人坚持做对的事情的结果是可以很不普通的!雪球，2019-05-08

这里的「坚持」不是咬牙硬撑，是把一套枯燥的流程重复很多遍：写表、过十问、等价格、记账、复盘。它不要天赋，只要你不中途换方法。

最后说清楚这门课不做什么。它不承诺让你赚钱，也不教你怎么赚得更快。它只承诺一件事：帮你少犯那些本来可以避免的错——不懂就买、亏了就加、赚了就跑、把杠杆当勇气、把运气当能力。

所以别用今年的收益率检验它。用这个标准：三年后，你还能不能把自己的每一笔持仓解释清楚——为什么买、当时怎么估的、逻辑变没变、什么情况下会卖。能解释，你就在对的路上；解释不了，赚了也只是运气。

本讲作业：今天写完你的一页纸

不要等「研究清楚了再写」，现在就写，写完存成文档或拍张照：

  1. 能力圈表至少五行，含一行你亏过钱的公司。
  2. 不为清单五条，每条右边写清它防的是哪个具体错误。
  3. 买入前十问里至少回答三问，每问一句话。
  4. 给现在每一个持仓写一条卖出触发条件，不写成本价。

三个月后回看。你会发现大部分条目需要改——那正是它在起作用的证据。

回顾：三个问题

点选项，立刻看解析

1. 复盘一笔投资时，最该记录的是什么？

2. 建立能力圈表时，最能说明问题的一栏是什么？

3. 哪种研究节奏更接近段永平的做法？

这是最后一讲。如果你只问一个问题，就问这个：我的清单里，哪一条其实是在自我安慰？把你的四张表发给正在运行本工作区的 agent，让它逐条追问，尤其是那些你写得很顺、却举不出一个具体例子的条目。
