# Notes

## 学习者画像(初始假设)

- 普通个人投资者,不是职业基金经理。
- 已经接触过价值投资的概念(巴菲特、护城河、能力圈),但缺少把它们串成决策顺序的训练。
- 手机阅读为主,单次学习时间碎片化。
- 想解决的真实问题:拿不住好公司、跌了不敢买、容易被热点和宏观叙事带走。

## 教学取舍

- **以书为纲,不以书为限。** 主线按《段永平投资问答录》的两册结构(投资逻辑 / 商业逻辑),但重组为"认知 → 筛选 → 估值 → 交易 → 纠错"的顺序,便于形成操作流程。
- **引文优先用一手来源。** 段永平的话全部来自网易博客、雪球(ID: 大道无形我有型)、公开演讲与访谈;转述自二手书评的内容会标注来源。
- **每讲一个可带走的动作。** 不是"理解一个概念",而是"写下一行字 / 画出一张表 / 回答一个问题"。
- **反例和正例配对。** 只讲成功案例会让人误以为可以复制;每讲尽量配一个"段永平自己也犯过的错"。

## 待确认(不影响开课)

- 是否要针对某一类行业(消费、互联网、制造)做加餐。
- 是否要把"公司财报怎么读"扩成独立一讲(目前放在估值一讲里)。

## 写作规范

- 正文中文,单讲 2500–4000 字。
- SVG 一律用样式类着色,禁止写死 `fill="#..."` / `stroke="#..."`。
- 测验三题,选项长度接近,正确答案位置分散,必须带解释。
- 每讲末尾给出一个可查证的一手链接,以及相邻讲次的跳转。
