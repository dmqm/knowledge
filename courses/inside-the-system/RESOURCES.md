# 置身事内 Resources

围绕兰小欢《置身事内：中国政府与经济发展》收集的可信来源。本书以地方政府投融资为主线：上篇讲微观机制，下篇讲这些机制累积出的宏观现象。

## Knowledge

- [书：兰小欢《置身事内：中国政府与经济发展》（上海人民出版社 · 世纪文景）](https://book.douban.com/subject/35546622/)
  本工作区的核心文本，也是一切概念的**第一出处**。上篇：地方政府权力与事务、财税与政府行为、投融资与债务、工业化中的政府角色；下篇：城市化与不平衡、债务与风险、国内国际失衡。每章末尾附作者亲写的「扩展阅读」书单，是本主题最好的进阶路径。用来看：任何论断请回到原书核对，而不依赖转述。
- [文章：兰小欢谈《置身事内》前言、数据说明与结语摘编（复旦大学经济学院）](https://econ.fudan.edu.cn/info/1024/19122.htm)
  作者亲撰文字的官方转载，含全书发展模式的三大特点（重土地轻人 / 重规模重扩张 / 重投资重生产轻消费）。用来看：十分钟抓住全书框架，以及作者「描述是什么、为什么，而非站队」的自我定位。
- [播客：声东击西 #226〈和兰小欢聊「置身事内」〉](https://etw.fm/226)
  作者本人口述的入门访谈，约 56 分钟。用来看：暂时不想读文字时，先听作者如何讲政府与市场的关系、为什么每个人「置身事内」。
- [书：周飞舟《以利为利：财政关系与地方政府行为》（上海三联书店）](https://book.douban.com/subject/10587755/)
  分税制与「土地、财政、金融三位一体」发展模式的社会学经典，正对应本书第二章的延伸方向。用来看：土地财政的机制细节，以及基层财政被抽空后的后果。
- [书：周黎安《转型中的地方政府：官员激励与治理（第二版）》](https://book.douban.com/subject/27120243/)
  系统提出「行政发包制 + 政治锦标赛」框架，是本书「官场+市场」与招商引资动机的理论来源。用来看：地方官员为什么有动力拼命发展经济，以及这种激励的代价。
- [书单：《置身事内》扩展阅读汇总（豆瓣豆列）](https://www.douban.com/doulist/147093821/)
  读者按章节整理的作者推荐书目。用来看：想按章节深入时，直接从这里挑下一本。

## Wisdom (Communities)

- [豆瓣《置身事内》图书讨论区](https://book.douban.com/subject/35546622/discussion/)
  围绕本书的读者提问与争论（含对书中观点的商榷）。社区规范一般，不算严格把关，搜一下即可发现「城投公司是不是怪胎」「第一章是否太浅」这类真实分歧。用来看：把你的理解公开讲出来、被不同意见挑战，检验自己是否真的读懂。建议发帖前先自己用「事权 / 财权 / 土地财政 / 城投」把问题说清楚。
