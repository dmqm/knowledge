核心概念速查表

读新闻、读文件、看讲义时随手查这一页。每条一句话；术语以本表为准。按全书线索分组：上篇（政府如何参与）在前，下篇（宏观后果）在后。

财政与央地关系

事权
政府要承担哪些公共事务、要花哪些钱，也就是支出责任。在中国，事权层层下压，越到基层越要「办事」。
财权
政府取得收入、决定收入如何分配的权力（征税、收费、分成）。分税制之后，财权总体向中央集中。
财力
政府实际可支配的收入总量，约等于自有收入加上转移支付。财权小，可以用转移支付把财力补回来。
分税制
1994 年起把主要税种的收入按比例在中央与地方之间划分，中央拿大头，并配套建立转移支付制度。它重塑了此后的央地财政关系。
转移支付
中央把集中起来的财政收入返还、补助给地方，用来填地方的收支缺口、均衡地区差距。
行政发包制
中央把目标与责任层层「发包」给下级政府，下级在属地内获得较大自由裁量权，同时承担结果责任。
条块关系
「条」指自上而下的部门系统，「块」指属地政府；同一件事同时受部门的垂直管理和地方的横向领导，权限与责任常常相互交错。 用来看：为什么一项政策在部门与地方之间会「打架」，以及责任该由谁负。

土地与融资

土地财政
地方政府围绕土地取得的收入与税收，核心是国有土地使用权出让收入，并带动建筑、房地产相关税收。 别混：它说的是「收入」。
土地金融
以土地或其收益权作抵押、注入融资平台，把未来的土地增值贴现到今天来借钱，从而放大建设融资规模。 别混：它说的是「融资」，关键在于杠杆。
城投公司
地方政府设立的融资平台公司，替政府借款、发债，用土地等资产抵押或担保。 别名：地方政府融资平台。它特指承担政府投融资职能的平台，不等于一般国企。
地方政府债务
地方政府及其融资平台形成的债务，大致分为账面上的显性债务，与平台、担保等形成的隐性债务。 别混：不能把「地方债」只理解成公开发行的债券。
政府引导基金
政府出资、并吸引社会资本共同投资特定产业的基金，是招商引资与产业政策的一种工具。 难点：财政目标（就业、税收、本地产业）与市场化财务回报并不总是一致。

政府与增长

招商引资
地方政府为吸引企业落地，提供土地、税收优惠、补贴、基础设施与审批便利等一揽子条件。
生产型政府 / 服务型政府
生产型政府以组织生产、扩大投资、做大经济总量为首要目标；服务型政府以提供公共服务、改善民生与营商环境为首要目标。转型方向是从前者走向后者。
官场+市场
周黎安的提法：地方官员在官场上的晋升竞争，与其辖区在市场中的经济表现相互绑定，从而形成强大的发展激励。
政治锦标赛
一种官员晋升机制：上级用可度量的指标（长期主要是经济增速）横向比较同级官员、择优提拔，使他们在辖区之间展开竞争。
外部性与规模经济
先行者承担研发与市场风险、收益却被后来者分享（外部性），而重资产行业又存在「产量越大、单位成本越低」的规模经济；这两点构成政府介入产业、分担前期风险的理由。 用来看：为什么重资产行业里，单靠企业自发投资可能不足。
复杂信息
上级难以掌握地方的真实信息，只能靠可度量的指标来考核与协调；这既给下级留下裁量空间，也带来信息失真与激励扭曲。 用来看：为什么考核指标一变，地方行为就跟着变。

城市化与不平衡

房价与土地供应
房价不只看需求，也看土地供给：供给弹性小、供地少的城市房价涨得更快；人口大量流入而供地指标未同步，就是「人地错配」。
户籍与城市化
户籍决定能否在务工城市平等落户、享受公共服务；它限制劳动力自由流动，使城市化滞后于工业化，地区收入差距也难以靠迁移自然收敛。

债务与风险

债务风险 / 去杠杆
债务要靠未来现金流偿还；高位债务遇冲击会陷入「债务—通缩」循环。去杠杆指压低债务增速，难点在于收得太紧会引发违约与衰退，所以强调「结构性」、区别对待，而非一刀切。
影子银行
银行通过理财、信托、资管等「表外」渠道，把资金投向地方融资平台与房地产企业，绕开了监管、使风险更不透明。 用来看：规范表外融资的政策，为什么与地方债、房价同频。

国内国际失衡

国内国际失衡 / 消费不足
由恒等式「储蓄 ≈ 投资 + 净出口」，居民消费不足、储蓄偏高时，国内投资消化不掉的产出会以对外顺差的形式出现，进而牵连产能过剩与贸易冲突；再平衡的方向是提高居民收入、健全社保、扩大内需。
