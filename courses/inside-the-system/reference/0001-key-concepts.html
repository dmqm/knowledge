核心概念速查表

读新闻、读文件、看讲义时随手查这一页。每条都是三段式：一句话定义，加上几句机制（它为什么这样运转），最后一行「用来看」告诉你什么时候会用到它。术语以本表为准。按全书线索分组：上篇（政府如何参与）在前，下篇（宏观后果）在后。

财政与央地关系

事权
政府要承担哪些公共事务、要花哪些钱，也就是支出责任。中国的特点是事权层层下压，越到基层越多「要办的事」；而办事要钱，于是事权与财力的匹配，就成了央地关系的核心矛盾。1994 年分税制主要重排了收入侧，支出侧（事权）的划分调整相对滞后，收支缺口由此产生。 用来看：为什么地方一边喊「钱不够」，一边还在大举借债搞建设。
财权
政府取得收入、决定收入如何分配的权力（征税、收费、分成）。分税制之后，主要税种的收入大头归中央，财权总体向中央集中，地方留下的部分不足以覆盖其支出责任。关键要记住：财权是「权」的口径，不等于「钱」的口径——财权小，还可以靠转移支付把财力补回来。 用来看：分清「地方没有收税权」和「地方没有钱」是两件事。
财力
政府实际可支配的收入总量，约等于自有收入加上转移支付。这是「钱」的口径，和「权」的口径要分开：一个地方可能没有多少税权，但靠上级的返还与补助，仍能维持运转和办事。看一个地方到底有没有钱，要看财力，而不是只看它留了多少税。转移支付的分配方式，还会反过来影响地方的行为。 用来看：别把「财权上收」直接等同于「地方没钱」——中间隔着转移支付。
分税制
1994 年起把主要税种的收入按比例或按税种在中央与地方之间划分，中央拿大头，并配套建立转移支付制度。它重塑了此后的央地财政关系：中央财政能力大幅增强，地方则在「事多钱少」的结构下，转向土地与融资平台去找收入。可以说，后面几讲的土地财政、城投、地方债，都要从这次改革讲起。 用来看：任何关于地方收入、土地财政、地方债的新闻，其实都站在分税制这条线上。
转移支付
中央把集中起来的财政收入返还、补助给地方，用来填地方的收支缺口、均衡地区差距。它大致分两类：一类是「返还」，把地方该得的给回去；一类是「补助」，真正起再分配作用，向欠发达地区倾斜。它让财权小的地方仍能维持基本运转，但补助怎么分、按什么标准分，也会影响地方的行为与努力方向。 用来看：理解「中央给钱、地方办事」这套运行的中间环节。
行政发包制
中央把目标与责任层层「发包」给下级政府，下级在属地内获得较大自由裁量权，同时承担结果责任。它像一种「责任到人」的治理方式：上级定目标、给压力，下级自己想办法完成。好处是动员能力强、执行快；代价是容易层层加码、数据失真，以及「只问结果、不问手段」。 用来看：为什么一项上级目标到了基层会变成「硬指标」，也为什么会出现形式主义。
条块关系
「条」指自上而下的部门系统（如财政、国土、环保各级厅局），「块」指属地政府；同一件事同时受部门的垂直管理和地方的横向领导，权限与责任常常相互交错。一个地方的环保部门，既要听上级环保系统的，也要听本地政府的；两套指挥线不一致时，就会出现「政策打架」、推诿或「选择性执行」。 用来看：为什么同一项政策在部门与地方之间会扯皮，以及出了事该由谁负责。

土地与融资

土地财政
地方政府围绕土地取得的收入与税收，核心是国有土地使用权出让收入，并带动建筑、房地产相关税收。制度前提是政府垄断城市建设用地的一级市场：先征收、收储、整理，再按计划出让；2002 年经营性用地推行招拍挂之后，土地从协议出让走向公开竞价，出让收入成为地方（尤其是政府性基金预算）的重要来源。 别混：它说的是「收入」。用来看：为什么地价一冷，地方财政就吃紧。
土地金融
以土地或其收益权作抵押、注入融资平台，把未来的土地增值贴现到今天来借钱，从而放大建设融资规模。政府不便直接大额举债，于是成立平台公司去借款、发债，用「赚钱的项目带不赚钱的项目」把整片城建打包融资。关键在杠杆：它把「地价会涨」这个假设，变成了整条链条的抵押基础。 别混：它说的是「融资」，关键在于杠杆。用来看：为什么地价、房价的波动会放大成债务风险。
城投公司
地方政府设立的融资平台公司，替政府借款、发债，用土地等资产抵押或担保。它是「政府想做、但制度上不能直接做」的融资难题的产物，因此它的信用，很大程度上依赖政府的隐性背书。当平台还不上钱，就会出现「续贷」「展期」「平台整合」这类新闻。 别名：地方政府融资平台。用来看：读到「某城投非标违约」，就知道这是土地金融链条末端的信号。
隐性债务
不以政府名义直接借、但实际上由地方政府承担偿还或兜底责任的债务，典型如融资平台债务、政府担保、以及长期拖欠的工程款等。它不在政府公开的债务账本上，却会在需要时变成财政负担，所以「地方债」要分显性（政府债券）与隐性两部分看。隐性债务规模不易准确统计，这也是风险处置要反复「摸底、甄别」的原因。 用来看：区分「政府欠的」和「政府平台欠的」，是读懂债务新闻的第一步。
地方政府债务
地方政府及其融资平台形成的债务，大致分为账面上的显性债务，与平台、担保等形成的隐性债务。显性债务口径清楚、成本相对低；隐性债务分散、成本高、不透明。处置思路常被概括为「开前门、堵后门」：给正规的举债渠道留口子，同时压降不规范的表外与隐性渠道。 别混：不能把「地方债」只理解成公开发行的债券。
政府引导基金
政府出资、并吸引社会资本共同投资特定产业的基金，是招商引资与产业政策的一种工具。逻辑是用财政的钱「撬动」社会资本，把市场化机构引到本地产业上来。难点在于：政府的财政目标（就业、税收、本地产业）与市场化机构的财务回报目标并不总是一致，久拖之下可能出现「募资难、退出难」。 难点：财政目标与市场化财务回报并不总是一致。用来看：一条「某地设立百亿产业基金」的新闻，先问它的钱从哪来、要什么回报。

政府与增长

招商引资
地方政府为吸引企业落地，提供土地、税收优惠、补贴、基础设施与审批便利等一揽子条件。它把「竞争」从企业之间延伸到了地方政府之间：你不出优惠，企业就去别处。好处是地方有动力改善环境、大办基建；代价是可能演成「补贴竞赛」、重复建设，以及地方保护。 用来看：为什么相邻的城市会争抢同一个大项目。
生产型政府 / 服务型政府
生产型政府以组织生产、扩大投资、做大经济总量为首要目标；服务型政府以提供公共服务、改善民生与营商环境为首要目标。这对概念是全书的总纲。生产型政府的三个特点——重土地轻人、重规模重扩张、重投资重生产轻消费——既解释了快速工业化，也解释了失衡与风险；转型是换一个「目标函数」，而不是让政府退场。 用来看：一条「把民生纳入考核」的新闻，正是转型在考核端的信号。
官场+市场
周黎安的提法：地方官员在官场上的晋升竞争，与其辖区在市场中的经济表现相互绑定，从而形成强大的发展激励。它一次解释了两件事：一方面地方拼命发展经济；另一方面出现重复建设、地方保护等副作用。因为两者是同一套激励的两面，改革的关键，往往就是改激励本身。 用来看：为什么地方对 GDP、对大项目如此上心。
政治锦标赛
一种官员晋升机制：上级用可度量的指标（长期主要是经济增速）横向比较同级官员、择优提拔，使他们在辖区之间展开竞争。它的力量在于「可度量」——指标能量化，才能被比较、排名、考核；也正因如此，指标一变，地方行为就变。长期以增速为主要标尺，就解释了「重规模、重扩张」。 用来看：理解干部考核指标为什么是这套体系的「方向盘」。
外部性与规模经济
先行者承担研发与市场风险、收益却被后来者分享（外部性），而重资产行业又存在「产量越大、单位成本越低」的规模经济。这两点构成政府介入产业、分担前期风险的理由：如果没人愿意当那个「先烧钱的人」，产业可能起不来。但干预也可能过度，比如补贴出过剩产能。 用来看：为什么重资产行业里，单靠企业自发投资可能不足。
复杂信息
上级难以掌握地方的真实信息，只能靠可度量的指标来考核与协调。这既给下级留下裁量空间（才能因地制宜办事），也带来信息失真与激励扭曲（为了指标而做表面文章）。换句话说，「考核什么」很大程度上决定了「下面做什么」。 用来看：为什么考核指标一变，地方行为就跟着变。

城市化与不平衡

房价与土地供应
房价不只看需求，也看供给：供给弹性小、供地少的城市房价涨得更快。中国的情况是人口大量流入少数大城市，但建设用地的指标分配没有同步跟上，形成人地错配——「人到了，地没到」。背后既有指标分配制度，也有土地财政的激励：地越稀缺，出让收入越值钱。 用来看：为什么大城市房价偏高，不能只怪「人太多」。
户籍与城市化
户籍决定能否在务工城市平等落户、享受公共服务，它限制了劳动力的自由流动。结果之一是城市化滞后于工业化，出现大量「人户分离」、留守儿童与空巢老人并存；劳动力不能完全流向收入更高的地方，地区收入差距也就难以靠迁移自然收敛。换句话说，户籍不只是一张证件，它影响的是要素市场的效率。 用来看：为什么「放宽落户」常被视为一次要素市场改革。

债务与风险

债务风险 / 去杠杆
债务要靠未来现金流偿还；高位债务遇冲击会陷入「债务—通缩」循环。去杠杆指压低债务增速。判断债务好坏有三条：收益能否覆盖成本、期限是否匹配、现金流是否稳健。它的难点在于收得太紧会引发违约与衰退，所以强调「结构性」、区别对待，而非一刀切；而且它不是把债务清零，是让债务增长慢于收入增长。 用来看：读到「去杠杆」「化债」「展期」，先分清压的是哪个部门。
债务—通缩
一种自我强化的收缩机制：资产价格下跌、收入下降时，名义债务不变，实际债务负担反而变重。于是债务人被迫抛售资产来还债，抛售又压低资产价格，还债因此更难。它解释了为什么在高债务环境里，一次本来普通的冲击，可能被放大成明显的收缩。 用来看：为什么「资产价格」是债务风险链条的命门。
刚性兑付
投资者默认「无论项目好坏，总会有人兜底」的预期。它让风险定价失真：既然有人兜底，投资者就不太关心项目本身的风险，资金也更容易流向问题主体。打破刚性兑付（让该违约的违约）是风险处置的关键一步，但推进太快又可能引发连锁反应，所以要拿捏节奏。 用来看：为什么「打破刚兑」总被反复讨论，又总是小心翼翼。
影子银行
银行通过理财、信托、资管等「表外」渠道，把资金投向地方融资平台与房地产企业，绕开了监管、使风险更不透明。中国的影子银行常被称作「银行的影子」——钱还是从银行出来，只是从表内挪到表外，以绕开信贷额度、资本与投向的约束。它带来层层嵌套、期限错配与信息不透明；2018 年前后的资管新规正是冲着这些通道去的。 用来看：规范表外融资的政策，为什么与地方债、房价同频。
间接融资
企业主要从银行借钱（间接融资），而不是从股市、债市直接融资。中国的融资以银行主导的间接融资为主，这让风险更多集中在银行体系，也让信贷成为宏观调控的主要抓手；它与「债务—通缩」叠加时会更脆弱。 用来看：为什么很多债务风险的新闻，最后都指向银行体系。

国内国际失衡

国内国际失衡 / 消费不足
由恒等式「储蓄 ≈ 投资 + 净出口」，居民消费不足、储蓄偏高时，国内投资消化不掉的产出会以对外顺差的形式出现。消费不足有多重机制：居民收入份额偏低、社保不足带来预防性储蓄、高房价挤出、地方重投资轻民生、收入与城乡差距。顺差又牵连产能过剩与贸易冲突，而关于贸易冲突的成因，书里并列了储蓄过剩、美国自身储蓄与美元地位、规则与产业竞争、统计口径等多种解释，不替读者裁决。 用来看：再平衡的方向是提高居民收入、健全社保、扩大内需。
预防性储蓄
因为担心未来的养老、看病、孩子教育等支出，人们为「以防万一」而多存钱、少消费。社会保障越不完善，这种动机越强，全社会的消费率就越低。它是「消费不足」最常被提到的机制之一，也和高房价、收入分配一起起作用。 用来看：为什么「健全社保」会被当作扩大内需的关键一环。
全球储蓄过剩
美联储的伯南克在 2005 年提出的解释：中国等高储蓄国的资本大量外流、流入美国，压低了美国的利率，推高了美国的消费与贸易逆差。它把美国的逆差从「某国贸易政策的结果」，重新理解为全球储蓄分布与资金流动的结果——提醒我们，一国的顺差是全球资金流动的另一面。书中把它作为多种并列解释之一。 用来看：讨论中美贸易摩擦时，别只盯着一国的关税清单。
